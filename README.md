# 📊 Gantt Task

Інтерактивна діаграма Ганта для відстеження виробничих задач — побудована на чистому TypeScript без зовнішніх UI-фреймворків. Відображає задачі по етапах і відповідальних, синхронізує скрол заголовка та підтримує згортання груп.

---

## ✨ Можливості

- **Групування** задач по етапах та виконавцях
- **Два типи барів:**
  - `solid` — задача з датою початку та кінця (синій заповнений бар)
  - `ghost` — задача без кінцевої дати (контурний бар)
- **Сьогоднішня лінія** — вертикальна відмітка поточного дня на часовій шкалі
- **Підсвітка вихідних** — суботи та неділі виділені сірим фоном
- **Локалізація** — місяці відображаються українською
- **Collapse/Expand** — клік на етап або виконавця згортає/розгортає рядки
- **Синхронізований скрол** — заголовок і тіло прокручуються разом
- **Валідація даних** — задачі без жодної дати пропускаються з виводом помилки в консоль

## 🚀 Запуск

### 1. Встановлення залежностей

```bash
npm install
```

### 2. Компіляція TypeScript

```bash
npm run build
```

### 3. Запуск локального сервера

```bash
npm start
```

Відкрийте браузер за адресою, яку виведе `serve` (зазвичай `http://localhost:3000`).

## 🧪 Тести

```bash
npm test
```

Тести охоплюють:

- `getTaskPosition` — обчислення відступу (`left`) та ширини (`width`) бару в днях
- `resolveTaskBar` — 4 кейси відображення бару залежно від наявності дат:

| insertedAt | startDate | endDate | Результат |
|:---:|:---:|:---:|---|
| ✅ | ✅ | ✅ | Solid бар: `startDate → endDate` |
| ✅ | ❌ | ✅ | Solid бар: `insertedAt → endDate` |
| ✅ | ❌ | ❌ | Ghost бар на день `insertedAt` |
| ✅ | ✅ | ❌ | Ghost бар на день `startDate` |
| ❌ | ❌ | будь-яке | ❌ Задача пропускається, помилка в консоль |

## 📐 Інтерфейс GanttTask

```typescript
interface GanttTask {
  id: string;
  stage: string;          // Назва етапу (напр. "ВИРОБНИЦТВО")
  assignee: string;       // Ім'я виконавця
  avatarUrl: string | null;
  title: string;          // Назва задачі
  insertedAt?: string;    // ISO 8601 (дата створення)
  startDate?: string;     // YYYY-MM-DD
  endDate?: string;       // YYYY-MM-DD
}
```
